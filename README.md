# Media Downloader

Media Downloader là một ứng dụng quản lý tải xuống các nội dung được phép tải, lưu file và theo dõi tiến trình.

## Features

- Tải xuống các nội dung đa phương tiện
- Lưu file đã tải xuống
- Theo dõi tiến trình tải xuống
- Tìm kiếm nội dung
- Phân loại nội dung
- Tải xuống hàng loạt

## Installation

1. Clone the repository
2. Run `npm install`
3. Run `npm start`

## Usage

1. Open the application in your browser
2. Enter the URL of the media you want to download
3. Click the Download button
4. Monitor the download progress
